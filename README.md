Ik heb een inventory iterface gemaakt en hun huis stijl in een [figma](https://www.figma.com/design/fNaT4QVETbZ12CNLGDG8vO/interface-inventory---styleguide-label-vier?t=DaqRWLfLaJqlCfyY-0) bestand en daarna,
